# Web Interface

This directory contains the frontend for LOFin (Lost Object Finder).

The web application allows users to request the location of a lost object and view detection results generated by the Raspberry Pi.

## Features

* Simple and responsive user interface
* Search for a specific object
* Sends search commands to Supabase
* Polls for updates from the Raspberry Pi
* Displays captured images of detected objects
* Supports the **Last Seen** feature, showing the most recent image of an object before it disappeared from view
* Indicates if the Raspberry Pi is offline or not responding

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla)
* Supabase JavaScript SDK

## Workflow

1. The user enters the name of the lost object.
2. The web application creates a command entry in Supabase.
3. The Raspberry Pi continuously checks for pending commands.
4. If the object is found, the Raspberry Pi:

   * Captures an image,
   * Uploads it to Supabase Storage,
   * Updates the detections table.
5. The web application polls the database for updates and displays the result to the user.

## Configuration

Update the following values in the frontend code before deployment:

```javascript
const SUPABASE_URL = "YOUR_SUPABASE_URL";
const SUPABASE_ANON_KEY = "YOUR_SUPABASE_ANON_KEY";
```

## Running the Web Interface

Since the application is built using static web technologies, it can be opened directly in a browser:

```text
Open lofin.html
```

Alternatively, serve it using a local web server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Database Requirements

The following Supabase tables are required:

* `commands`
* `detections`

A public storage bucket is also required for storing detection images.

## Notes

* Ensure that the Supabase credentials used in the frontend have appropriate permissions.
* The Raspberry Pi must be running and connected to the internet for object searches to succeed.
